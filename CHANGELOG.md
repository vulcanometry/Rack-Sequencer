# Changelog

## [2.1.0] - Unreleased

### Added
- Loop a track's pattern while the song moves on (Shift+click TRACK).
- Track names, shown in the info bar next to the song name.
- Per-note probability, edited in the new PROB view.
- Swing (50–75%), in the right-click menu.
- Per-track clock rate, from /8 to x4.
- Euclidean rhythm fill for a track.

### Changed
- MOD and PROB views turn each other off.
- Gate length follows each track's own step length.

### Fixed
- Looping tracks no longer lose a step when PAT IN arrives just after a step.

## [2.0.1] - 2026-11-11

### Fixed
- Crash when the module is deleted from a patch.

### Changed
- Code split into separate files and classes.

## [2.0.0] - 2026-11-02

- First release for VCV Rack 2.
